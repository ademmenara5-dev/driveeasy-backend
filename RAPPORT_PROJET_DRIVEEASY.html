1. Contexte & Périmètre Fonctionnel

La plateforme DriveEasy modernise la gestion de location courte et moyenne durée d'une agence automobile en remplaçant une architecture monolithique vieillissante par une architecture en microservices Spring Boot 3.x / Spring Cloud complétée par une interface web en Angular 22 (bonus).

Objectifs Métier Implémentés

  • Gestion du Parc Automobile : gestion des caractéristiques, prix journalier, statut (DISPONIBLE, LOUE, MAINTENANCE) et kilométrage.
  • Gestion de la Clientèle : suivi des pièces d'identité, âge légal (≥ 21 ans) et validité des permis de conduire.
  • Cycle de Vie des Locations : réservation, départ, retour avec calcul automatique des pénalités de retard et remises de fidélité (Fidèle : 5%, VIP : 10%).
  • Tableau de Bord & Indicateurs : suivi du chiffre d'affaires, taux d'occupation et véhicules les plus loués.
  • Stockage en RAM Exclusif : respect strict de la contrainte d'absence totale de base de données (structures thread-safe ConcurrentHashMap).

3. Réalisation Backend

Règles de Calcul & Gestion

Prix Total = (Nombre de Jours × Prix Journalier) - Remise Fidélité + Pénalité de Retard
- Remise Fidélité : STANDARD (0%), FIDELE (5%), VIP (10%)
- Pénalité de Retard : 1.5 × Prix Journalier × Nombre de Jours de Retard
- Éligibilité Client : Âge ≥ 21 ans ET Date Expiration Permis > Date du Jour
- Promotion Fidélité Automatique : FIDELE après 5 locations terminées, VIP après 15 locations

Filtre Personnalisé API Gateway

La classe RequestLoggingGatewayFilter intercepte chaque requête, mesure le temps de traitement en millisecondes et injecte les en-têtes de traçage :

  • X-Response-Time-Millis
  • X-DriveEasy-Gateway-Timestamp

4. Réalisation Frontend (Angular 22)

Le frontend moderne implémente l'ensemble des 8 écrans exigés par le cahier des charges :

  • /dashboard : Tableau de bord avec indicateurs visuels et statistiques du parc.
  • /vehicules : Grille de cartes avec recherche, filtres (carburant, prix max, statut).
  • /vehicules/new & /vehicules/:id/edit : Formulaire réactif avec validations.
  • /clients : Liste paginée avec alertes automatiques en cas de permis expiré.
  • /clients/:id : Fiche client avec badge d'éligibilité et historique complet.
  • /locations/new : Assistant de réservation en 4 étapes (Client → Période → Véhicule disponible → Devis & confirmation).
  • /locations : Gestion des statuts et boutons d'action (Départ, Retour, Annuler).
  • /locations/:id/retour : Enregistrement kilométrique, calcul des pénalités et récapitulatif imprimable.

5. Instructions de Lancement & Validation

docker-compose up -d

# 2. Démarrer Eureka Server (8761)
cd service-registry && mvn spring-boot:run

# 3. Démarrer Config Server (8888)
cd ../config-server && mvn spring-boot:run

# 4. Démarrer les Microservices Métier (8081, 8082, 8083)
cd ../vehicule-service && mvn spring-boot:run
cd ../client-service && mvn spring-boot:run
cd ../location-service && mvn spring-boot:run

# 5. Démarrer l'API Gateway (8080)
cd ../api-gateway && mvn spring-boot:run

# 6. Démarrer le Frontend Angular (4200)
cd ../driveeasy-frontend && npm start
